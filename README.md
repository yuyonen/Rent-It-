# Rent It! 🏠

Palveluiden markkinapaikka, jossa käyttäjät voivat myydä ja vuokrata palveluita kuten ruohonleikkuuta, koiran ulkoiluttamista ja muita hyödyllisiä palveluita.

## Ominaisuudet

- ✅ Käyttäjäprofiili ja rekisteröityminen
- ✅ Palvelun listaaminen myyntiin
- ✅ Palveluiden selaaminen ja haku
- ✅ Viestintä ostajan ja myyjän välillä
- ✅ Arvostelujen jättäminen

## Teknologia Stack

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: Node.js + Express + TypeScript
- **Tietokanta**: PostgreSQL
- **Autentikaatio**: JWT
- **API**: RESTful API
